# FIDUCIA data

La carpeta `data/` separa datos de investigacion y analitica de la base operacional SQLite usada por la aplicacion.

- `synthetic/`: datos generados artificialmente y reproducibles.
- `external/`: datos de fuentes publicas documentadas con metadata.
- `raw/`: datos originales sin modificar.
- `processed/`: datasets transformados y listos para analitica.

No guardes contrasenas, JWT, CVV, numeros completos de tarjetas, numeros completos de cuentas, PIN, credenciales ni secretos.
